# Phase 1 version 2, Set 1: wagon, points and handover

12 files, 27 pieces, 423 g, 12h 07m of printing. Every file is in `stl/` (print orientation) and `sliced_p1s/` (Bambu Lab P1S, 0.4 mm nozzle, quantity already on the plate). Pictures and details of every part: `phase1_reprint_v2_set1_parts.pdf`.

Print this set first. Build one wagon with your existing wheels and roll it on an existing lead rail before printing the rest.
